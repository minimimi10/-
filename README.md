# -# GitHub User Finder

## Автор
Ульяна Инчина

## Описание
GUI-приложение для поиска пользователей GitHub с использованием GitHub API.
Позволяет добавлять пользователей в избранное и сохранять их в JSON.

## Функциональность
- Поиск пользователей
- Отображение списка
- Добавление в избранное
- Сохранение данных

## Использование API
Запрос:
https://api.github.com/search/users?q=USERNAME

Метод: GET

Ответ содержит список пользователей (login, id, avatar_url и др.)

## Как запустить
1. Установить зависимости:
   pip install requests

2. Запустить:
   python main.py

## Пример использования
- Ввести "octocat"
- Нажать "Поиск"
- Выбрать пользователя
- Добавить в избранное

## Тесты
- Пустой ввод → ошибка
- Повторное добавление → не добавляется
